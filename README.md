# Shubham Chand - Developer Portfolio

A responsive portfolio covering backend engineering, distributed systems,
cloud reliability, AI-assisted diagnostics, and fintech.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
All styles, scripts, and the resume PDF are local assets.

## GitHub Pages

Publish the repository root from the deployment branch in
**Settings > Pages > Build and deployment > Deploy from a branch**.
The `.nojekyll` file keeps the site as plain static HTML, CSS, and JavaScript.

## Update

- Edit `index.html` for portfolio content.
- Edit `styles.css` for layout and styling.
- Edit `script.js` for project filtering and print behavior.
- Replace `Shubham_Chand_Resume.pdf` to update the downloadable resume.

Review employer confidentiality requirements before publishing or updating
project names and metrics. The site does not include proprietary source code,
customer logs, or actual internal architecture diagrams.
